📋 បញ្ចូលឈ្មោះសិស្សម្តងច្រើននាក់

សូមបញ្ចូល ឬចម្លងឈ្មោះសិស្សដាក់ក្នុងប្រអប់ខាងក្រោម (អាចសរសេរ ឈ្មោះ, ថ្នាក់ ឬតែឈ្មោះសុទ្ធក៏បាន)៖

✏️ កែប្រែព័ត៌មានសិស្ស

📊 នាំចូលទិន្នន័យសិស្សពី Excel (.xlsx, .xls, .csv)

សូមជ្រើសរើសឯកសារ Excel ដែលមានឈ្មោះសិស្ស និងថ្នាក់៖

📁 ចុចត្រង់នេះ ឬទាញទម្លាក់ឯកសារ Excel ទីនេះ គាំទ្រឯកសារ .xlsx, .xls, .csv

☁️ ធ្វើសមកាលកម្មទិន្នន័យជាមួយ Google Sheets

រក្សាទុក និងទាញយកទិន្នន័យសិស្សពី Google Sheets ដើម្បីឱ្យទូរស័ព្ទដៃ ឬកុំព្យូទ័រដទៃទៀតអាចប្រើប្រាស់ និងបង្វិលកងរួមគ្នាបានគ្រប់ទីកន្លែង។

⚪
មិនទាន់បានភ្ជាប់ជាមួយ Google Sheet ឡើយ សូមបិទភ្ជាប់ Google Web App URL ខាងក្រោមដើម្បីចាប់ផ្តើម
-
⚡ Web App របស់អ្នក Google Apps Script ដែលបានភ្ជាប់ស្រាប់
https://script.google.com/macros/s/AKfycbxh9oWB7OVGVGqb6O8d1Q_g1XCenXyyuEzY-V0ZPCcXWiYRK6_Vq2hdTvRSuQYTXB8_FQ/exec
🛠️ របៀបបង្កើត Google Apps Script Web App (៥ ជំហាន)៖
  1. បើកសន្លឹកកិច្ចការ Google Sheet ថ្មីមួយនៅ sheets.new
  2. ចូលម៉ឺនុយ Extensions (ផ្នែកបន្ថែម) > Apps Script
  3. លុបកូដចាស់ចេញ រួច Paste កូដខាងក្រោមនេះចូល
  4. ចុច Deploy > New deployment រួចជ្រើសរើសប្រភេទ Web app (កំណត់ Execute as: Me និង Who has access: Anyone)
  5. ចុច Deploy រួចចម្លង Web App URL យកមកបិទភ្ជាប់ក្នុងប្រអប់ខាងលើ ជាការស្រេច!
